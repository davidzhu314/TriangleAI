# Handoff — David D2: case loader and validator

What landed: `client/src/case/`, the real loader:
- `loadCase` reads a package from any of three sources, runs the eight §3.5 checks and converts the case to a metres, Y-up `LoadedCase`. The three sources are a bundled folder, an imported `case.zip` and a physics-served package.
- Its parts:
  - `sources.ts`: the readers and `listBundledCases()`.
  - `unzip.ts`: our own zip reader on `DecompressionStream`.
  - `glb.ts`: GLB parsing, triangle count and metadata strip.
  - `validate.ts`: one function per §3.5 row.
  - `decimate.ts` and `decimate.worker.ts`: vertex-clustering decimation in a Web Worker.
- Eight broken packages in `tests/fixtures/broken/`, one per rule. They are generated by `tools/broken/build.ts` and the tests check they match byte for byte.
- `tools/lib/zip.ts`: a deterministic zip writer for D6-min.

How to use:
```ts
import { listBundledCases, loadCase } from '../case';

const cases = await listBundledCases();                    // reads cases/index.json
let result = await loadCase(cases[0].source);              // bundled folder
result = await loadCase({ kind: 'zip', data: droppedFile }); // a File or Blob from drag-and-drop; never uploaded
// physics-served (D3a/D5): { kind: 'url', baseUrl: 'http://127.0.0.1:8765/cases/phantom3/', origin: 'physics' }

if (!result.ok) showErrors(result.results);   // schema errors with JSON-pointer `path`; nothing loaded
else {
  const c = result.case;                       // metres, Y-up
  c.validation;                                // warnings and notices, in §3.5 order
  c.planningOnly;                              // show the "Planning only" badge
  c.targets.filter((t) => !t.reachable);       // grey these out
  // Offer a fix: a warning's `fix` (rescale, flip_axes, decimate). To accept it, load again with it:
  result = await loadCase(sameSource, { fixes: [...acceptedFixes, warning.fix] });
}
```
- Draw the mesh: parse `c.mesh.glb` with GLTFLoader, then apply `c.mesh.toWorld` with `Matrix4.fromArray` to the root. The GLB stays in mm and RAS. The matrix includes any rescale or flip fix the player accepted, and three.js handles the mirror when a flip makes the determinant negative.
- Privacy notices are logged silently: put them in a log or details view, not in a dialog.

Known gaps:
- The loader does not check that every vessel has a GLB node of the same name.
- Decimation flattens node hierarchies and cannot handle compressed GLBs.
- No ZIP64 or encrypted zips.
- The axes check assumes the targets sit above the entries, which holds for every planned case: femoral or radial access to arch targets.
- `physics/cases/` (D3a) does not exist yet, so the physics-served path is tested only through the same `url` reader.
